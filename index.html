02 / TECH STACK

这些作品用到的技术

不是“我会什么”，而是“数据怎么从 A 到 B”。

数据层

Python / Pillow / JSON；生成图、解析 YOLO/COCO、跑审计 CLI。YOLO 归一化，COCO 像素，id 差 1。

页面层

HTML / CSS / JS；fetch 数据、Canvas 画框、localStorage 存复核状态。

3D 层

Three.js；Scene/Camera/Renderer、BufferGeometry + Points、Raycaster 选框。

评估层

IoU / NMS / AP；TP/FP/FN 匹配、P/R/F1、per-class AP、PR 曲线。

交付层

Linux / Git / Node 静态服务器；批处理、版本管理、本地预览。

边界

数据自建、Eval 预测为模拟；不冒充真实产线，不声称训练过大模型。
