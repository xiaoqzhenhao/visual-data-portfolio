Rule Engine / 01

把“数据不干净”
拆成可执行的检查项

标注质检最怕两件事：只靠人眼看，和只报一个“有问题”。这套规则把问题落到具体样本、具体框，并区分 error（必须退回）与 warn（需要人确认）。

阈值配置

阈值集中放在一处，按业务调整；当前值与 Python 审计 CLI 完全一致，保证网页复核与离线批处理口径相同。

PARAMVALUE说明
min_wh0.002归一化宽或高低于此值 → 零面积框
tiny_area0.0005归一化面积低于此值 → 过小框，warn
dup_iou0.85两个框 IoU 达到此值 → 重复框
max_aspect8.0长宽比超过 → 异常框，warn
coord_tol1e-6坐标越界的容差
