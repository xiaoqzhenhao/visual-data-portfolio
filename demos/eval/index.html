怎么读这张图？（老师版）

Precision = TP / (TP+FP)：报出来的框有多少是对的。

Recall = TP / (TP+FN)：该找的目标找回了多少。

F1 = 2PR/(P+R)：P/R 的平衡。

mAP：每个类别 PR 曲线下面积的平均；越高越好，但要看 IoU 阈值和数据集。

NMS：去掉同一目标的重复框。打开后 FP 通常会下降，Recall 可能略降。

当前预测是模拟输出，用于教学/演示；真实项目把 pred 换成模型输出即可。
